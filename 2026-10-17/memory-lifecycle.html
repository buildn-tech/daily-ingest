Agent memory: audit the lifecycle, not just recall

A fresh wave of memory work is making the operational lifecycle explicit: capture, update, temporal state, forgetting, poisoning, and cost. The practical implication is sharp: a useful agent memory must be inspectable and reversible, not merely “better at remembering.”
