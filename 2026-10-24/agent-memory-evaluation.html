Agent Memory: Forgetting, Drift, and Worth

24 October 2026 · adaptive lane

Memory research is moving past “can the agent recall?” The useful tests now ask whether memory survives changing facts, respects deletion, earns its token and latency cost, and resists poisoned formation.

Signal map

Selection rule: prefer benchmarks that expose failure modes a product can actually instrument.

MemDerive

freshevolving data

What: A diagnostic benchmark for memory over changing records.

Why: Final-answer accuracy hides which memory nodes became stale.

Use: Run it against project decisions, client assets, and status changes.

Now: Any long-lived workspace will accumulate contradictions.

Caveat: preprint results need local replication.

Action: Add a “changed since last answer” test set.

Memory worth

fresheconomics

What: Learns which memories deserve scarce context and compute.

Why: More memory can increase cost without improving decisions.

Use: Rank memories by expected task value per token.

Now: Persistent agents make retrieval budgets operational.

Caveat: value estimates depend on task distribution.

Action: Log retrieval cost beside outcome quality.

Experience memory

test before claimclosed loop

What: Controlled evaluation of experience memory in driving agents.

Why: Benefits vary with the warmup pool and scenario mix.

Use: Keep matched no-memory and retrieval baselines.

Now: “Memory improved it” is too weak as a product claim.

Caveat: driving is a narrow environment.

Action: Freeze baseline, pool, and metric before rollout.

Bemula forgetting

controlprivacy

What: Tests retention, relearning, attack leakage, and over-deletion.

Why: A delete button is not proof of forgetting.

Use: Define deletion SLAs for personal and client context.

Now: User trust depends on invalidated facts staying invalid.

Caveat: deletion can damage adjacent valid knowledge.

Action: Add paired preservation questions to QA.

Open benchmark →

MemForm poisoning

securitymemory writes

What: Measures attacks that manipulate how persistent memories are formed.

Why: Retrieval defenses cannot repair a poisoned source.

Use: Gate durable writes behind provenance and review.

Now: Agents increasingly ingest web, email, and tool output.

Caveat: attack settings may not match your stack.

Action: Separate observed facts from agent-derived summaries.
