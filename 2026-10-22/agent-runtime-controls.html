Telemetry gaps can corrupt adoption decisions

WARNINGincident · 6 Oct
  • Signal: agent activity undercounted; no historical backfill
  • Use now: audit metrics before using them for ROI

What it is

GitHub reported that SDK-based agent sessions omitted originating IDE metadata, undercounting activity and misattributing some sessions to CLI.

Why it matters

A polished dashboard can still be measuring the wrong population; missing history cannot be recovered.

  • Version telemetry schemas explicitly.
  • Separate billing truth from usage truth.
  • Next: Add metric provenance to client reports.
Caveat: This is a GitHub-specific incident, not evidence all agent telemetry is unreliable.
