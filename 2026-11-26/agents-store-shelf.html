Microsoft Agent Framework: malicious PyPI uploads pulled

active incidentsupply chain
  • Microsoft security advisory · Nov 25, 2026
  • Affected: agent-framework 1.26.1 and 1.26.2 on PyPI
  • Unauthorized uploads containing credential-stealing code
  • Repo temporarily offline during investigation; pin to 1.26.0

What it is. Two releases of a major agent framework were uploaded to PyPI without authorization and carried credential-stealing code that executes at interpreter startup — meaning any agent sandbox, CI pipeline, or container build that pulled an affected version hands over whatever credentials it holds.

Why it matters now. This is the first time an agent-framework package — the exact dependency layer agent sandboxes auto-install — was the attack vehicle, not just a generic typosquat. With coding agents installing dependencies unprompted, lockfiles and provenance checks are now the security boundary of the agent itself.

Buildn / client use. Immediate: audit lockfiles and CI logs for agent-framework 1.26.1/1.26.2 anywhere in Buildn or client infra; rotate if found. Standing: provenance checks and SBOM gates for every package an agent runtime installs — the same policy Env Vault applies to decryption capability.

  • Agent framework hit first
  • Executes at import
  • Lockfile = boundary
Microsoft removed the packages and publishes remediation steps; confirm the safe-version timeline before unpinning.

Cloudflare "Search for Agents": /.well-known/search endpoint

try todayagentic web
  • Cloudflare launch · Nov 25, 2026 · beta, all plans
  • Dashboard toggle → AI Search instance for the domain
  • Exposes /.well-known/search returning Markdown results
  • No crawling required by the consuming agent

What it is. One-click agent discoverability: a site owner turns on a toggle and publishes a standardized search endpoint that returns agent-friendly Markdown, so agents consume content through a controlled, rate-limited interface instead of scraping HTML.

Why it matters now. This is the first mainstream deployment of a well-known path for agent content consumption — the agentic-web "readable, callable" thesis getting actual plumbing. Note what it changes: the site owner, not the crawler, decides what an agent can see; the agent gets a stable contract instead of brittle DOM scraping.

Buildn / client use. Enable on a staging domain this week and point a coding agent at docs retrieval through it — direct test for the agent-ready-web thesis, and a lead magnet for clients whose docs agents currently scrape messily. Audit exposure before production: CI logs, private files, anything the index shouldn't leak.

  • Agent discovery in one toggle
  • Markdown contract, not scraping
  • Owner-controlled exposure
The endpoint reveals what the index chose to include — verify the allowlist before production domains, and plan rate limits.
