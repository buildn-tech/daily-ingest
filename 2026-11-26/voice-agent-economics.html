Gemma 4 31B on Telnyx: open weights inside the telephony network

try todayreleasetelnyx
  • telnyx.com release note · Nov 25, 2026
  • Model: google/gemma-4-31B-it · Apache 2.0 · 128K context
  • $0.32/1M input · $1.20/1M output · $0.16/1M cached
  • 12 languages · hosted on Telnyx GPUs, US + UAE (Priority tier)
  • No third-party API key or external endpoint

What it is. One release making an open-weight Google model a first-class citizen of a hosted voice stack: the model runs on the vendor's own GPUs next to telephony, so conversation text never leaves the network, and the license leaves you free to lift the workload off Telnyx later.

What's new since Nov 11. That lane covered self-hosted local voice; this is the hosted middle ground — vendor convenience with open-weight escape hatches. The per-token prices are the first openly listed LLM-slot pricing in this lane's coverage.

Buildn / client use. Direct for Egypt fitout lead-gen work: a multilingual inbound/outbound agent (Arabic + English on one model) with auditable weights and US/UAE residency is now a config, not a project. Caveat stands from the buyer guide: ask for total cost per finished call (STT + LLM + TTS + telephony), not the LLM line item.

  • Open weights, hosted price
  • One model, 12 languages
  • No model-layer lock-in
Token prices are not call prices — the note links no per-minute total and no benchmark. EU residency is absent (US + UAE only), a real constraint for European callers.

FCC robocall-blocking vote lands December 17

regulatorycontext
  • topcalls.ai analysis · Nov 26, 2026
  • Draft would let carriers block calls "highly likely" illegal
  • Adjacent: FCC AI-call disclosure still only a proposal; TCPA revocation-window change under comment

Why it matters now. For anyone shipping outbound voice agents commercially, the compliance layer is moving at the same pace as the capability layer. A blocking regime based on likelihood-of-illegality puts the burden on the deployer to be provably legitimate (consent records, disclosure scripts, opt-out honor latency).

Buildn / client use. If voice agents go into a client's outbound flow, ship disclosure and opt-out handling as product features from day one — the December vote makes "we handle it later" a launch blocker, not a backlog item.

  • Blocking vote Dec 17
  • Disclosure still proposal-stage
  • Design consent in, now

PenGPT: a transformer for handwriting and sketches

worth exploringresearch
  • greydanus.github.io · Nov 12, surfaced on HN Nov 25 (399 pts)
  • Small transformer generating handwriting/sketch strokes from text
  • Effort split: 80% data, 15% speed, 5% architecture

What it is. A compact, browser-runnable model that writes and draws — the pen-path analogue of a language model, built mostly out of dataset curation rather than clever architecture.

Why it matters now. The "80% data" lesson mirrors everything else in this lane's week: capability is increasingly a data-pipeline achievement. Also a genuinely fun interactive demo for client sessions about what small models can do on commodity hardware.

Buildn / client use. Signature/handwriting personalization is a plausible creative-tool integration (Cards, signing flows, education). Low stakes, high demo value.

Qwen on 5,600 Lambdas: 80× negative profit

engineeringeconomics
  • noahbuilt.it · surfaced Nov 25 · H2O-Lightning (Qwen3.5-4B fine-tune)
  • 32 layers → 5,600 idempotent Lambda jobs over S3 handoff
  • 17s per ~4k-token read · $8.40/1M tokens vs $0.10 hosted
  • 92% parallelizable, 8% serial; matrix mults want GPUs

What it is. A well-executed negative result: splitting a model call across thousands of Lambdas is technically feasible and economically hopeless. Useful as the cheapest possible proof of why serving infrastructure exists — and a demonstration that open-weight models are approachable as ordinary software from a plain application developer.

Buildn / client use. The "model engineering is not so hard in 2026" takeaway supports Buildn's local/open-model stance: layer-level tinkering is now an application-developer activity. Keep for the Env Vault local-trusted-MCP design conversation — this is what not to build, and why the boundary layer matters more.

  • Clean negative result
  • Open models are approachable
  • GPUs earn their place
