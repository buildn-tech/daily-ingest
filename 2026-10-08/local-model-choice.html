Local Model Choice + Provider Portability

GitHub Copilot CLI can now discover compatible Ollama models inside a live session. The practical shift is not “local is private”; it is provider choice becoming an explicit, testable control.

Signal map

fresh release → provider picker → local runtime → policy check

Local model selection does not automatically disable telemetry or guarantee offline operation.
