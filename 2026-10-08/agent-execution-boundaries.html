Agent Execution Boundaries

Local sandboxing is now generally available across GitHub Copilot CLI, app, and VS Code Agent Host. The important move is to make filesystem, network, credentials, and MCP access policy—not agent good intentions.

Signal map

Model execution and tool isolation are separate concerns; changing the model must not change the sandbox policy.
