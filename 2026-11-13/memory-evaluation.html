Executive readout. The fresh research signal is moving memory evaluation from “was something retrieved?” to “did it change the agent’s next action, and did that change help?” For Buildn, the practical move is to instrument memory deliveries and keep consolidation reversible before chasing larger memory stores.

strong signalpaper

MemUse: delivered is not used

arXiv:2611.01718v1 · 8,000 SWE-bench episodes

What it is: A reference-free evaluator that reconstructs each memory delivery, checks novelty and relevance, then follows later actions and consequences.

Why it matters: In the study, 51–80% of relevant entries were still unused; end-task success hid both helpful and harmful memory effects.

Buildn/client use: Add delivery IDs, exact placement proofs, and a short credit window to agent traces. Report “used/helped/harmed,” not only retrieval hit rate.

  • Measure memory at point of use
  • Separate relevance from influence
  • Expose repeated-delivery waste

MEMOIR: screen, then attribute

arXiv:2611.07631v1 · 1,905 LoCoMo QA pairs · 6.8ms write path

What it is: A training-free lifecycle combining evidence-preserving merges, retrospective attribution, and UCB exploration so retrieval credit can change with observed usefulness.

Why it matters: It treats consolidation and retrieval as one loop. Reported evidence Recall@5 improved 11.92 points over bare cosine retrieval.

Buildn/client use: Use reversible supersession for changing project facts; retain source links when summaries are compressed; explore under-retrieved memories rather than letting early winners monopolize retrieval.

  • Keep merges certifiable
  • Preserve provenance on retire
  • Use feedback as ranking signal

SoMem: documents as memory

arXiv:2611.11929 · linked summaries + source records

What it is: Self-organized memory where the agent revises linked topic documents while the runtime validates evidence and derives temporal and relational views.

Why it matters: The design is a useful middle ground between raw transcripts and opaque vector stores: semantic organization is flexible, while evidence links remain inspectable.

Buildn/client use: Prototype project memory as a folder of topic documents with immutable source records. Let agents revise summaries, never erase the source.

  • Human-readable memory substrate
  • Model-portable state
  • Evidence-backed revisions
