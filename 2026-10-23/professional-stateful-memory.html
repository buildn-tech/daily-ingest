DSV-Mem — professional visual state is still hard

high signal39.6% vs 81.8% human

DSV-Mem tests tax reconciliation, sales forecasting, incident postmortems, campaign design, and robotics evaluation. The failure is not basic OCR; it is state reconstruction across revisions, authority changes, and derived questions.

  • Track authority explicitly
  • Keep version lineage
  • Require multi-artifact evidence

Use now: Build a self-ledger for any client artifact workflow: current state, prior state, change event, authority, evidence links.

Caveat: Benchmark results are not production guarantees; the scenarios are curated.

DyadMem — separate who, how, and what happened

design patternmemory lifecycle

DyadMem distinguishes user profile, fact, agent identity, agent method, agent knowledge, and episodic memory. It evaluates capture, update, recall, and QA separately, exposing failures that a final answer score hides.

  • Namespace memory types
  • Measure delete/update quality
  • Keep lineage to evidence

Use now: Map Hermes/Buildn memory into these namespaces before adding another retrieval layer.

Caveat: The dataset is synthetic; validate taxonomy against real consented workflows.

Source: DyadMem · code

MeMoREval — choose evidence modality by task

cost-awareembodied agents

MeMoREval separates memory modality from backend and reports write cost, read cost, and cost per successful request. Camera frames plus scene graphs outperform text-only summaries for the tested embodied tasks.

  • Store evidence, not prose only
  • Measure write/read separately
  • Use structured state selectively

Follow-up: For Buildn reports, preserve source snapshots or artifact references when summaries would erase layout, revisions, or visual authority.
