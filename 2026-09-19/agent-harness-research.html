RAFT targets stateful troubleshooting agents

Industry trackStateful retrieval
  • Updated: 2026-09-18
  • Source: arXiv 2609.20754

What it is. RAFT proposes a stateful retrieval-augmented framework for troubleshooting agents and is listed as accepted to EMNLP 2026 Industry Track.

Why it matters. Troubleshooting is where stale context, repeated symptoms, and incomplete histories make stateless retrieval brittle.

Buildn/client use. Shape Buildn support and incident workflows around evolving case state, not a fresh search on every turn.

  • History informs retrieval
  • Symptoms stay connected
  • Next checks are explicit

Next: Model one recurring client issue as a stateful case file and compare retrieval quality. · Direct source ↗

SkillAA proposes attributed skill-graph updates

New paperSkill lifecycle
  • Updated: 2026-09-18
  • Source: arXiv 2609.20455

What it is. SkillAA describes attribution-guided skill-graph updating with targeted validation and rollback.

Why it matters. Skills are mutable production logic; updating them without attribution or rollback turns learning into silent drift.

Buildn/client use. Apply versioned skill changes, targeted validation, and rollback to client-specific agent playbooks.

  • Changes have provenance
  • Validation is scoped
  • Bad updates can revert

Next: Add an evidence link and rollback marker to every experimental skill change. · Direct source ↗

Caveat: This is a title-level signal until the full paper is reviewed; do not assume implementation maturity.

AgentPProf profiles long-horizon agents

New paperRuntime profiling
  • Updated: 2026-09-18
  • Source: arXiv 2609.20301

What it is. AgentPProf introduces a semantic profiler for long-horizon AI agents.

Why it matters. Long tasks fail through accumulated latency, loops, and context decisions that ordinary request traces hide.

Buildn/client use. Instrument Buildn workflows around semantic steps: retrieval, tool choice, retries, context release, and completion.

  • See loop waste
  • Find semantic bottlenecks
  • Tune the right layer

Next: Define five semantic spans for one long-running agent workflow. · Direct source ↗

Caveat: Profiling quality depends on consistent span taxonomy; avoid creating an unreadable trace dump.
