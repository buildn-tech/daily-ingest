Daily Ingest Dossier — Agent Identity + Access

2026-11-21 · lane selected because identity is the missing control plane for delegated work

Agent security is moving from prompt hygiene to non-human identity governance. The practical baseline is simple: inventory agents, give each one an attributable identity, issue short-lived scoped credentials, and preserve the human sponsor without pretending the agent is the human.
