Parallel Code: run coding agents side by side in isolated worktrees

New toolOrchestration
  • Launched 2026-11-21 · parallelcode.app
  • Open-source CLI; npm / Homebrew
  • Supports Claude Code, Codex, Copilot Agent

What it is. An open-source CLI that runs Claude Code, Codex, and Copilot Agent simultaneously, each in its own isolated Git worktree on the same task, so you compare outputs instead of queueing agents.

Why it matters now. The bottleneck in agentic development has shifted from generating attempts to scheduling and reviewing them; worktree isolation is the simplest sane answer and this packages it for the three dominant CLIs.

Buildn/client use. Directly usable in Buildn's own repo for implementation attempts; the isolation pattern also informs how Buildn OS task execution could fan out.

Caveats. Day-one tool; roadmap (more platforms, IDE plugins) is unproven. Review cost scales with parallelism.

Action. Install via npm and run one two-agent bake-off on a real Buildn issue.

ReleaseDeveloper surface

What it is. Codex CLI now opens files and subagent transcripts in a side panel next to the conversation, reducing context-switching during agent sessions.

Why it matters. The terminal agent is acquiring the review ergonomics of an IDE; visibility into subagent transcripts is the practical answer to "what did the spawned agent actually do".

Use. Better supervision of multi-step agent work in Buildn's day-to-day coding.

Action. Update and use the transcript panel during the next delegated refactor.

Claude Code 2.1.329 fixes silent wrong-branch reviews

Bugfix that mattersRelease
  • Published 2026-11-20

What it is. A fix for review flows that could silently operate on the wrong Git branch — the kind of quiet correctness bug that undermines trust in agent-performed reviews.

Why it matters. Wrong-branch reviews produce confident, plausible, wrong feedback; anyone using agent PR review should update immediately and re-check any recent agent reviews.

Action. Update Claude Code now; spot-check the last few agent-authored reviews for branch correctness.

localcode: open-source agentic coding on your Mac, one command

OSSLocal-first
  • github.com/mjwsolo/localcode · on HN 2026-11-23

What it is. A local, self-hosted agentic coding setup that runs with a single command on macOS, combining local models with a coding-agent loop.

Why it matters. Pairs with the local-model lane: fully local coding agents (no code leaves the machine) are now a working configuration, not a demo.

Caveat. Small project, early; quality depends on the local model used.

Action. Try it with Inkling 2 Mini or a Qwen coder for a confidential-data experiment.
