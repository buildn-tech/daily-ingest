Cloudflare Agent Access Model

  • task-scoped agents
  • identity brokering
  • continuous mediation

What: A proposed access architecture for agents that combines strict identity brokering with ongoing trust evaluation.

Why: Static API keys are a poor fit for agents that discover and act across systems.

Use: Design a broker that issues the smallest credential for one task and can revoke it.

  • Scope by task
  • Log every delegation
  • Revoke without redeploying
