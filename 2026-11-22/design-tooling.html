Daily Ingest Dossier — Design Tooling + Design-to-Code

2026-11-22 · Daily Ingest Dossier

Figma shipped five agent-era releases in ten days: an agent inside Dev Mode, native 3D with a code path, and an admin allowlist for MCP clients. The design-to-code seam is turning into a governed agent conversation.

Signal map

The design-to-code path now runs through an agent, and the admin console is the gatekeeper for which agents are allowed.

Figma agent lands in Dev Mode

High leverageAI
  • Released 2026-11-19
  • Inspect, compare versions, bulk asset links

What it is: Prompt the Figma agent inside Dev Mode to explain designs, diff versions, request code snippets, and get bulk download links.

Why it matters: The design-to-code handoff, the seam most client work stalls on, now has an in-tool agent. It directly affects Buildn's design-delivery workflow: fewer handoff documents, more interrogating the artifact.

Use cases
Use in next client design review; ask it for code snippets before writing components.
  • Handoff becomes a dialogue
  • Version diffs on demand
  • Bulk asset retrieval

3D transform, shipped straight to code

New capabilityDesign
  • Released 2026-11-12
  • On-canvas x/y/z rotation; pairs with Figma Motion

What it is: Native 3D rotation with live previews, composable by the agent, exportable as CSS via Dev Mode or pushed through Figma MCP to a coding agent.

Why it matters: Perspective and depth used to be a developer task. Now a designer can author a real 3D scene and the code path is one MCP call away — a small but real client-differentiator for marketing pages.

Use cases
Hero sections and product pages; hand motion specs to Figma Motion instead of custom JS.
  • 3D without a 3D tool
  • CSS export, no plugin
  • MCP path for agents

Admin allowlist for OAuth apps and MCP clients

GovernanceEnterprise
  • Released 2026-11-17
  • Covers Cursor, Claude Code as MCP clients
  • Org/Enterprise rollout

What it is: Admins get an allowlist of approved OAuth apps including MCP clients, plus an Extensions tab to review requests.

Why it matters: The same agent-identity governance theme seen in Buildn OS work, arriving in a design tool. Client orgs will ask who can connect which agents to their files; Buildn can answer first.

Use cases
Set client org policies before rollout; mirror the allowlist pattern in Env Vault sharing.
  • Agents get explicit grants
  • Requests reviewed, not surprised
  • Precedent for Buildn policies

Multi-model image generation in one prompt

Worth tryingAI
  • Released 2026-11-18
  • 2/4/6 images per model, or 3 models in parallel

What it is: Make Image and Edit Image can fan out one prompt across counts or models, presenting options side by side.

Why it matters: It turns image production into an option-selection workflow — the same fan-out-then-select pattern agents use everywhere. Faster to acceptable assets for client work.

Use cases
Client moodboards and hero art; compare models' house styles once, then pin one.
  • Fewer re-prompts
  • Model comparison in tool
  • Select, don't settle
