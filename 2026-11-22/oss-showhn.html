trace2rules: evidence-backed AGENTS.md

Try todayOSS
  • https://github.com/rkkautsar/trace2rules
  • MIT · Python · v0.2.3 (2026-11-21)
  • Ingests Claude Code, Codex, Pi, OpenCode logs

What it is: A local CLI that mines your coding-agent session logs, audits existing AGENTS.md/CLAUDE.md rules against real sessions, and marks each rule observed, violated, unobserved, or already CI-enforced. Output is a proposal, never an auto-apply.

Why it matters: Most AGENTS.md files are folklore. This replaces vibes with verdicts — and it reads the exact session stores this machine already has (Claude Code, Pi, OpenCode). It can generate Hermes-side evidence for the PR-review skill too.

Use cases
Audit the main buildn repo's AGENTS.md; mine repeat friction into enforced rules.
  • Rules with receipts
  • Local-only, privacy-safe
  • DuckDB-backed, fast
Needs ~10+ local sessions for meaningful audits; detectors are heuristics — review every proposal.

OpenComputer: open-source Devin alternative

WatchOSS
  • https://github.com/diggerhq/opencomputer
  • Apache 2.0 · TypeScript · 1.3k stars · 218 releases
  • 2.6x faster first push than hosted cloud agents

What it is: An open, self-hostable platform for running computer-use coding agents in isolated sessions, from the Digger team. Active daily commits; production configs kept in a private deploy repo.

Why it matters: The "hosted agent vs owned agent" trade is becoming a real choice. For client work with confidentiality constraints, an owned computer-agent platform may beat sending repos to a hosted runner.

Use cases
Pilot for private-repo client tasks where hosted agents are a non-starter.
  • Owned infrastructure option
  • Bring-your-own model keys
  • Very active development
Young project; benchmark claims come from the vendor's own tests.

Straum: live Postgres aggregates, no triggers

Worth exploringOSS
  • https://github.com/janbjorge/straum
  • Show HN, 2026-11-21

What it is: Real-time aggregates over Postgres without triggers or extensions.

Why it matters: Dashboards and activity feeds are the first thing every client asks for and the first thing triggers/extensions complicate. A plain-python drop-in could simplify the v1 stack.

Use cases
Live task dashboards; real-time client reporting without ETL.
  • No schema surgery
  • Fits Next.js + Postgres v1
  • Early-stage, small surface

agent-mcts: tree search on top of Claude Code

SpeculativeOSS
  • https://github.com/natsu0529/agent-mcts
  • Show HN, 2026-11-21

What it is: Monte Carlo tree search orchestration over a coding agent, exploring multiple solution branches before committing.

Why it matters: An orchestration pattern, not a product: search-and-select applied to coding sessions. Even a skim of the architecture informs how Buildn workflows could branch-and-merge agent attempts.

Use cases
Compare against linear per-repo event histories; borrow for workflow branching design.
  • Search beats single attempts
  • Maps to Buildn branching plans
  • Cheap to study
