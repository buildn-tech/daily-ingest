Microsoft Clarity adds agentic analytics

Free to tryProduct
  • Announced 2026-11-04
  • Agent Activity dashboard + simulations + Ask Clarity
  • Free tool

What it is: Clarity can now show which AI agents visit a site and what they do, run simulations testing whether an agent can complete checkout or booking, and answer natural-language questions backed by session evidence.

Why it matters: Egypt fitout lead-gen work lives or dies on form and funnel friction. Agent traffic is small but growing, and Microsoft claims ~2M agents, double in three weeks. The simulation output is a literal fix list.

Use cases
Enable Clarity on client sites; run one simulation per key journey; fix popups and form walls.
  • Zero-cost first look
  • Simulation gives a fix list
  • Session-evidence answers
Simulations reflect Microsoft's test agent, not every real agent; detection accuracy is unproven.

ChatGPT starts keeping score

SignalResearch
  • https://www.getlooploop.com/news/marketing-analytics-first-half-of-november-2026-chatgpt-starts-keeping-score
  • First half of November 2026

What it is: Roundup of analytics changes centered on ChatGPT surfacing its own scoring/visibility data, with a warning not to read the AI referral line as the size of AI's effect.

Why it matters: Attribution for AI discovery is becoming a first-class metric. For marketing clients, "visibility in answer engines" will soon be a deliverable with a number attached.

Use cases
Add an AI-visibility line to client monthly reports; measure before promising GEO work.
  • Attribution gets quantified
  • Referral ≠ total effect
  • Reportable metric arriving
