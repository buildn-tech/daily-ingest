Code, craft, and the making of nested folders

engineering blog2026-08-03test before adoption
  • DIRECT — https://www.figma.com/blog/code-craft-and-the-making-of-nested-folders/

What it is

Figma’s account of delivering nested folders by using code and staging as proposals instead of waiting for complete handoffs.

Why it matters

The valuable pattern is not role blur; it is short, inspectable feedback loops with a real artifact.

Buildn / client use

Run client discovery as a thin vertical slice in staging, with a named decision owner and visible acceptance checks.

Caveat. Merging rough work into staging is safe only with containment, rollback, and a clear distinction from production.

Next move: For the next ambiguous request, open a small proposal PR before drafting a full implementation plan.

Tracewell

repo2026-08-05test before adoption
  • DIRECT — https://github.com/Tracewell-code/Tracewell

What it is

An early open-source visual workspace for workflow automation construction, execution, and observation.

Why it matters

The interface framing—build, run, observe—matches the operational lifecycle client automations need.

Buildn / client use

Evaluate its workflow model for internal prototypes; borrow the surface pattern even if the project is not adopted.

Caveat. A very new repository: validate maintainer activity, security model, and deployment maturity before client use.

Next move: Open the repo and assess licensing, persistence, credentials, and run-history design in 30 minutes.

hud-mode

repo2026-08-05test before adoption
  • DIRECT — https://github.com/adrida/hud-mode

What it is

A compact heads-up display for coding-agent status and completion state.

Why it matters

Supervision fails when an agent’s state is invisible; a minimal status surface can make review timing deliberate.

Buildn / client use

Try it on one local coding task and compare interruption frequency with the current terminal-only workflow.

Caveat. It is early-stage and should receive no credentials or privileged execution rights merely for convenience.

Next move: Test it in an isolated repository and keep the existing terminal log as the source of truth.
