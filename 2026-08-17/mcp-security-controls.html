MCP Security Controls

The MCP security story moved from inventory to enforceable network policy: detect protocol traffic, expose shadow connections, then narrow access to approved portals. The useful move is to establish visibility before blocking, because local stdio and off-network paths remain outside the same lens.

Cloudflare detects MCP traffic

High leverageblog
  • Updated: 2026-08-14
  • Best fit: Agent connectors + egress

What it is

Cloudflare Gateway identifies inspected MCP requests using protocol signals such as MCP-Protocol-Version.

Why it matters

Teams can discover shadow MCP without maintaining a brittle domain list, then turn detection into an allow/block policy.

Buildn / client use

Add an MCP inventory checkpoint to client security reviews and map approved servers to portal-only access.

Follow-up

Run a read-only Gateway log review; classify approved, unknown, and direct MCP destinations before enforcement.
