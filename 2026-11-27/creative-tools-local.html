AutoClip: local-first AI clipping with an MCP server

try todayrepo889★/day
  • github.com/zhouxiaoka/autoclip · 17.3k stars · Python + TS · 1,578 commits
  • Long video → shorts with subtitles, covers, and platform captions
  • Targets TikTok, Reels, YouTube Shorts, Douyin, Xiaohongshu
  • Zero subscriptions; MCP server means agents drive the pipeline

What it is. The open-source OpusClip alternative: a desktop tool that transcribes a podcast/interview/course, finds the clip-worthy moments, cuts vertical shorts, generates subtitles, covers, and per-platform captions. The MCP server is the differentiator — an agent can queue, cut, and publish as part of a workflow instead of a human clicking through an app.

Why it matters now. 889 stars/day says the market wants out of subscription clipping. For Buildn the interesting part is architectural: media production becoming an agent-callable pipeline means content repurposing (e.g. turning a client's fitout walkthrough video into social shorts) is a service line with near-zero marginal cost.

Buildn / client use. Obvious first pilot: take existing Egypt fitout project videos (or Buildn demo recordings) and produce a weekly shorts cadence for the Facebook-first lead-gen playbook. If the quality holds, "we run your video → shorts pipeline locally" is a productized offer OpusClip can't match on price.

  • Local GPU, no subscription
  • MCP: agent-driven cutting
  • Multi-platform captions
China-platform support is first-class (Douyin/Xiaohongshu); YouTube/Reels output needs a quality check on your footage before promising a client anything. Desktop tool — needs your own GPU time.

YouTube Ad Punisher: make the ad cost the viewer nothing

browsershow hn
  • github.com/antonpictures/youtube-punisher · HN 383 pts, 449 comments
  • Auto-reloads the page when an ad plays; economics flow to the creator, not the ad
  • The comment section is a live debate on ad economics vs blocker ethics

What it is. A pointed bit of protest engineering: instead of blocking ads (creator loses revenue), it reloads the page so the impression is wasted — the platform pays for serving, the creator keeps the view.

Buildn / client use. Not something to ship to clients. The value is in the HN thread's map of where ad-supported monetization is heading, which matters for any client with a content/creator revenue model. Also a small case study in "constraint-channelling" product design — attacking the incentive, not the surface.

  • Incentive-level protest
  • Good economics thread

Buildn / client use. Niche but real: fitout/architecture clients live in Blender or similar for walkthroughs — embedding live project dashboards (budget burn, timeline) inside a 3D presentation scene is a demo nobody else is showing. Bookmark for the next creative client conversation.
