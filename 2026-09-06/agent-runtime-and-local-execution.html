Devin Desktop v3.9.1018

released Sep 5local + worktree + cloud
  • Source: Devin Desktop next changelog
  • Key change: Cascade removed; Devin Local is now the only local agent

What it is: A desktop surface that makes Local, Worktree, and Cloud explicit top-level execution locations, with searchable worktrees and stronger review navigation.

Why it matters: Runtime choice is now visible to the operator instead of hidden inside a chat product.

Buildn/client use: Add an execution-location field to every delegated job; default low-risk edits to worktrees and route sensitive tasks locally.

Caveat: Migration and local trust prompts can change behavior across existing sessions.

Next: Test one task in each placement and compare recovery, review time, and data exposure.

Google Managed Agents

managed sandboxpreview lineage
  • Source: Google Blog
  • Pattern: AGENTS.md + SKILL.md + reusable remote environment

What it is: A hosted agent harness that provisions isolated Linux environments, uses tools, executes code, browses, manages files, and resumes state across interactions.

Why it matters: The reusable unit shifts from prompt to versioned instructions, skills, and environment state.

Buildn/client use: Package repeatable research or report-generation jobs as a skill with explicit artifacts and a bounded remote workspace.

Caveat: Preview APIs and remote state need retention, egress, and cost controls before production use.

Next: Build a tiny managed agent that produces one HTML artifact and records its inputs.

Vertex AI becomes Gemini Enterprise Agent Platform

migration signaldocs updated Sep 6
  • Source: Vertex AI release notes
  • Change: legacy release-note surface no longer updated

What it is: Google is redirecting current agent information from Vertex AI into Gemini Enterprise Agent Platform.

Why it matters: Product naming and documentation boundaries are becoming part of platform migration risk.

Buildn/client use: Maintain a vendor capability map with canonical docs, API owner, deprecation date, and replacement surface.

Caveat: Documentation migration does not by itself prove API compatibility.

Next: Inventory any Vertex references before starting a new agent integration.

Vercel AI Gateway: Gemini 3.8 Flash

try nowmodel portability
  • Source: Vercel changelog
  • 1M context · image/PDF/video · tool calling · 50% off through Dec 31

What it is: A long-context, multimodal, tool-capable route exposed through a stable gateway model ID.

Why it matters: A gateway makes bounded model trials cheap without rewriting the agent harness.

Buildn/client use: Run screenshot, PDF, and repository triage through the same evaluation harness as current models.

Caveat: Promotional pricing can distort durable unit economics.

Next: Run 20 representative tasks; record completion, tool errors, latency, and tokens.
