Platform Continuity + Security Baselines

The GitHub Models shutdown became an operational migration today: Spark lost creation access and has an August 31 export deadline. New CodeQL centralization and GitLab migration tooling make a practical continuity lane rather than a generic security roundup. The useful move is to turn these releases into a small, reviewable operating experiment—not a platform-wide rollout.

Upcoming deprecation of GitHub Spark on github.com

release notice2026-08-04
What
Spark is being retired: export editable code by August 31. Deployed apps stay up, but GitHub Models-backed llm() calls stopped July 30.
Why now
The immediate risk is not only downtime—it is loss of the only editing path for an unexported app.
Buildn / client use
Inventory Spark apps; export to repositories; search for llm(); replace inference, keys and billing deliberately.
Caveat
A deployed app surviving retirement does not mean its AI features survive.

FOLLOW-UP → Run the Spark export and llm() inventory this week.

Customize code scanning default setup at scale

release2026-08-04
What
Default CodeQL setup can reference an organization-level configuration, including one stored in another private repository through Git Source access.
Why now
It separates a maintained security baseline from repository-by-repository workflow copy/paste.
Buildn / client use
Store query packs, exclusions and threat models centrally; pilot one repository; decide override policy.
Caveat
Merged defaults can still change results; establish alert triage ownership before broad rollout.

FOLLOW-UP → Create a baseline config repository and test it on one service.

Migrate from GitLab to GitHub with GitHub Enterprise Importer

release2026-08-03
What
GEI now supports GitLab-to-GitHub Enterprise Cloud via gh gl2gh, including bulk scripting and GitHub-, S3-, or Azure-staged archives.
Why now
A repeatable importer reduces coordination friction for portfolio migrations.
Buildn / client use
Use a pilot repository to validate metadata, CI, runner, secret and compliance cutover assumptions.
Caveat
GitHub Enterprise Server is not a supported destination.

FOLLOW-UP → Write a migration acceptance checklist before moving any production repository.
