obra/superpowers — methodology sold as skills

HotSkillsMethodology
  • repo: github.com/obra/superpowers
  • 328k stars · 922 stars/day today
  • shape: skill bundles + slash commands encoding a dev process

What it is. An agentic skills framework that packages not just capabilities but a software development methodology — how to plan, implement, review, and hand off — as installable skills.

Why it matters. Most skill collections are tool manuals. Superpowers sells process, which is the same bet as Buildn's workflow templates: the durable value is the encoded method, not the prompt. Study how it names, chains, and versions skills.

  • Methodology is the moat, not tools
  • Skill naming/chaining worth copying
  • Distribution: installable, forkable

HKUDS/CLI-Anything — compile any app into an agent CLI

Try itAgent interfaces
  • repo: github.com/HKUDS/CLI-Anything · 67k stars
  • hub: clianything.cc, 200+ prebuilt connectors
  • pipeline: 7 phases from app source → CLI + tests + docs + skill file
  • targets: GIMP, Blender, LibreOffice, draw.io, OpenWebUI…

What it is. A generator that reads desktop-app source and emits a full command-line interface — command tree, session representation, tests, docs, and an agent-discoverable skill file. CLI-Hub distributes prebuilt ones via pip install cli-anything-hub.

Why it matters. It turns "agent uses app" from brittle screen-clicking into typed commands with predictable results. Direct template for Env Vault's local-MCP/CLI portal: wrap local systems in deterministic harnesses, keep MCP for the control plane.

  • Deterministic CLIs beat screen scraping
  • Skill file ships with the tool
  • Hub model = distribution flywheel
Generated CLIs are only as trustworthy as the generation run; audit the harness before letting agents act on real data.

OpenSRE — the agent that fixes red builds (for review)

AdoptCI/CDSelf-hosted
  • repo: github.com/Tracer-Cloud/opensre · public alpha
  • model: reads failed run → tests hypotheses → pushes fix PR
  • separates CI-caused vs code-caused failures
  • reports: failure rate, dev hours lost, main-red time
  • integrations: GitHub, K8s, CloudWatch, Datadog, Grafana, Slack

What it is. A self-hosted CLI agent for CI/CD reliability. When a run goes red it investigates immediately, distinguishes flaky infrastructure from real regressions, and opens a fix for human review. It also quantifies what unreliable CI costs in engineer hours.

Why it matters. Two reasons to run it this week: it's the review-gated agent pattern done concretely (agent proposes, human approves), and its failure-economics report is the kind of measurement clients understand instantly. Runs on your infrastructure with your models.

  • Fix cause, not rerun
  • Review-gated fix PRs
  • CI cost made visible
Public alpha — treat API surfaces as moving; pin a release before wiring into client pipelines.

cursor/plugins + unkernel — the surface layer consolidates

WatchInteropSandboxing
  • repo: github.com/cursor/plugins · 20k stars
  • repo: github.com/pithings/unkernel · Debian in WASM, <1s boot
  • unkernel: persistent browser data disk, SMP via web workers

What they are. Cursor published its plugin specification and official plugins — the IDE agent surface converging on the same skills/MCP vocabulary as everything else. Separately, unkernel compiles a real Linux kernel to WebAssembly and boots Debian in a browser tab in under a second, with a persistent data disk and networking.

Why they matter. One spec shape to track for Buildn MCP compatibility; one zero-install sandbox that could host client demos or bounded agent execution without any server. Both are plumbing, both lower the cost of every workflow built on top.

  • Track plugin spec for MCP parity
  • Browser VM = instant client demos
  • Sandbox-per-tab agent execution
