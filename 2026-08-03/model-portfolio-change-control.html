release2026-07-31

Gemini 2.5 Pro and Gemini 3 Flash deprecated

What changed
GitHub removed Gemini 2.5 Pro and Gemini 3 Flash from all Copilot experiences, directing users to Gemini 3.1 Pro Preview and Gemini 3.6 Flash.
Why it matters
A model picker is not a stable interface. Prompts, latency assumptions, and output review expectations need an owned replacement path.
Buildn / client use
Buildn: add model IDs and fallback acceptance tests to every agent runbook. Client work: prepare a one-page migration note before a preferred model disappears.
Caveat
Suggested replacements can differ in behavior and preview status; validate task quality, cost, and access before changing defaults.
Follow-up
Inventory Copilot workflows that name either deprecated model; run a representative task on the replacement.
release2026-07-31

Enterprise teams model policy targeting

What changed
GitHub’s public preview moves optional-model access from organizations to enterprise teams, with a baseline Enabled / Disabled / Optional policy.
Why it matters
It enables role-based frontier-model pilots without granting every employee the same catalog.
Buildn / client use
Buildn: propose a “pilot / production / prohibited” model matrix. Client work: scope privileged models to trained delivery teams.
Caveat
Access is additive: membership in any enabled team grants the model everywhere; organization-level settings deactivate in preview mode.
Follow-up
Model a test team and its memberships before enabling the preview.

Managing availability of Copilot models

What changed
GitHub documents the enterprise baseline and the migration implications of team mode.
Why it matters
The documentation provides the control-plane checklist needed to turn the preview into an auditable rollout.
Buildn / client use
Buildn: capture the pre-switch policy export. Client work: assign model ownership to enterprise administrators.
Caveat
Rollback restores the prior state, not policy edits made after entering team mode.
Follow-up
Record baseline settings and an owner before any preview opt-in.
