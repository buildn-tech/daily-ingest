Personal Context + Access

Useful agents are moving closer to the person: they remember objects, interpret surroundings, and work across organizational context layers. The design lesson is precise: make capture explicit, retrieval correctable, and access bounded by the user’s intent.

Signal map

capture → context layer → guided action → correction + audit

Under-covered lane: user-facing memory and accessibility, selected because it converts “agent context” from an enterprise abstraction into daily interaction design.
