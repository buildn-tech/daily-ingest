Released Aug 5Administration

Per-user AI credit limits

What it is: Figma admins can set a custom AI-credit limit for each user; users can request an increase when they reach it.

Why it matters: AI usage becomes a controllable operating budget instead of an ambient team-wide resource.

Buildn/client use: Map credit limits to project roles and review thresholds. Use requests as a lightweight approval signal for high-cost generation.

Caveat: A limit is not a value metric. Pair spend with accepted outputs, rework, and delivery time.

Follow-up: Draft a “credits per deliverable” pilot for one client project.

Released Aug 3Information architecture

Nested folders replace flat projects

What it is: Figma files now live in folders that can nest up to 10 layers, use colors, and inherit access from parent folders with narrower sharing available.

Why it matters: A project tree becomes a policy surface: client, engagement, phase, artifact, and audience can be represented without duplicating files.

Buildn/client use: Mirror Buildn engagements as folder boundaries. Keep intake, working files, review evidence, and published artifacts visibly separate.

  • Less duplicate project structure
  • Clearer access inheritance
  • Faster client handoff

Caveat: Inheritance can widen access accidentally; test one representative tree before migrating.

Released Jul 30Figma Make

Granular editing and annotation

What it is: Figma Make’s editing panel adds direct controls for spacing, typography, layout, device frames, and annotations that point the agent at a specific area.

Why it matters: The review loop gets less conversational and more spatial: “change this region” can be attached to the actual output.

Buildn/client use: Turn visual QA into structured annotations: location, expected behavior, severity, and acceptance screenshot.

Follow-up: Trial an annotation rubric on a single landing-page iteration.

Released Jul 24Design-to-code

Auto layout moves closer to CSS

What it is: Updated auto layout behavior is the default for new frames and aims to reduce implementation gaps; legacy frames can be reverted until January 2027.

Why it matters: Better correspondence between design constraints and CSS reduces handoff exceptions—the small mismatches that accumulate into client rework.

Buildn/client use: Use the updated behavior as the baseline for new system components; record exceptions rather than silently patching them in code.
