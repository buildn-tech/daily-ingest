release2026-07-27

Regional inference on AI Gateway

What: A single request option pins inference to US or EU, with served-region confirmation returned in the response.

Why it matters: It converts an informal residency promise into a request-level control that can be logged and checked.

Buildn / client use: Build a region assertion into client workflows handling residency-sensitive briefs.

Useful now: Without the setting, routing remains global; compliance is opt-in.

Caveat: Regional capacity can fail closed and commonly costs more.

Follow-up: Add region, provider, and served-region fields to one agent run log.

release2026-07-27

WebSocket mode for OpenAI Responses API

What: Persistent Responses API connections that continue with previous_response_id instead of resending full context.

Why it matters: Long tool-call rollouts can reduce repeated context transfer and improve interactive latency.

Buildn / client use: Benchmark a supervised, multi-tool client workflow against current HTTP behavior.

Useful now: The route supports store=false and Zero Data Retention.

Caveat: Persistent sockets require reconnect, timeout, backpressure, and audit handling.

Follow-up: Measure latency, token transfer, and recovery behavior across 20-tool test runs.
