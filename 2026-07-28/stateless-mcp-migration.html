MCP 2026-07-28 release candidate

What: A breaking, stateless-core MCP revision with extensions, stronger authorization alignment, and explicit state handles.

Why it matters: The protocol revision changes how remote tool servers scale, route, cache, and request user input.

Buildn / client use: Audit Buildn MCP servers for hidden session dependence; model durable state as explicit IDs.

Useful now: The release candidate starts the compatibility clock before final adoption.

Caveat: Stateless transport does not make an application stateless; handles still need access control and lifecycle rules.

Follow-up: Create a one-page inventory of session, stream, replay, and server-push dependencies.

Cloudflare Agents SDK v0.20.0

What: A concrete SDK v2 path that serves new and legacy MCP clients from a compatible route.

Why it matters: It turns the protocol change into a deployable migration pattern: factory handler, fallback, and parallel legacy support.

Buildn / client use: Use the handler pattern as a reference for Workers-hosted client tools.

Useful now: McpAgent is deprecated and feature-frozen.

Caveat: Sessionful RPC, standalone streams, replay, and pushed requests require deliberate bridging.

Follow-up: Prototype one read-only tool behind the v2 factory and exercise both protocol generations.
