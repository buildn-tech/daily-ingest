Buildn/client use. Useful pattern for client field operations: degrade gracefully, preserve operator visibility, and keep control paths explicit.

Remote Access generally available

product2026-08-18
  • Source · https://foxglove.dev/blog/remote-access-is-generally-available

What it is. Uses device tokens, short-lived credentials, and WebRTC/SFU relaying so robots behind firewalls can be viewed and controlled.

Buildn/client use. Borrow the connection model for secure remote workers: outbound-only gateway, short-lived session grants, independent viewer quality.

  • Practical now: Compare this gateway pattern with a self-hosted Buildn worker relay.
  • Keep provenance attached to every action.
Caveat. Cloud relay and vendor dependency may conflict with residency requirements.

release2026-08-18
