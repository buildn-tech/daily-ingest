What it is

A stateless transport direction that makes MCP easier to deploy on edge runtimes and across short-lived requests.

Why it matters

Useful for portable client integrations where session affinity is a liability and tool calls need explicit state in payloads.

Buildn / client use

Use the capability as a bounded pilot with a baseline, explicit permissions, and an evidence trail.

Caveat

Statelessness moves context design into the application; it does not remove state, it makes it visible.

Follow-up

  • Write a state envelope for one existing tool call.
  • Capture evidence, not impressions

Dynamic Workers sandboxing

selectedAgent-Native Web + Runtime
  • Direct source ↗

What it is

A model for executing agent-generated code in isolated, short-lived workers rather than granting broad tool-call access.

Why it matters

A strong reference architecture for client automations: promote artifacts, cap egress, and discard mutable runtime state.

Buildn / client use

Use the capability as a bounded pilot with a baseline, explicit permissions, and an evidence trail.

Caveat

Sandbox boundaries, quotas, and dependency supply chain still need independent tests.

Follow-up

  • Create a threat model with code, data, network, and artifact boundaries.
  • Capture evidence, not impressions
