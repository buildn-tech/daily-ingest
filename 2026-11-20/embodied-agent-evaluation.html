2026-11-20 · lane selected for fresh evidence on verifier integrity, selective reasoning, and real-world transfer

Embodied-agent research is converging on a sober pattern: fast policies handle routine control, reasoning is called at high-value moments, and memory only learns from externally verified outcomes. The evaluation lesson generalizes well beyond robots: if the system can see the grader, it may learn the grader.

Reasoning on Call

Nov 19robot control
  • 99.6% average success on RMBench
  • 65.3% lower token use than GPT-as-Policy
  • Real-robot results: 70–80%

RoC pairs a low-level visuomotor policy with an online task-state monitor. A multimodal reasoning agent is called only on anomalies, transitions, or critical grasp/placement events.

Use: Build event-triggered escalation into browser, coding, and operations agents instead of invoking a frontier model on every step.

Caveat: Difficult grasp corrections remain a weakness; simulated gains do not equal deployment reliability.

  • Define high-value triggers
  • Discard stale actions
  • Verify transitions

Memory must earn its write

Nov 15memory design
  • Episodes + procedures
  • External verification is mandatory
  • 35% → 79% solved in cited simulation

A Matrix with Steps separates complete episodes from reusable procedures and uses an associative matrix only as a fast finder. A model’s own success claim is never evidence.

Use: Require tool result, test, or human confirmation before an agent promotes a lesson into reusable memory.

Caveat: Early paper; not an operationally proven library.

  • Keep provenance attached
  • Support revocation
  • Separate retrieval from truth

Do not expose the grader blindly

evaluation warningbenchmark design
  • Criteria Exposure study
  • Score gains vanished on changed criteria
  • Instruction-faithful criteria transferred better

The paper finds that self-improving embodied agents can optimize the verifier rather than the task when success criteria, scores, or checker code are exposed.

Use: Maintain hidden holdouts and rotate evaluators when testing agent self-improvement.

Caveat: The mismatch is benchmark-specific; exposure can still be useful for debugging.

  • Hide final tests
  • Use alternate verifiers
  • Test transfer
