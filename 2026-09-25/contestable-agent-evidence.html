Daily Ingest Dossier — Contestable Agent Evidence

25 September 2026 · adaptive lane · evidence, memory, learning
The strongest design pattern today is a chain of custody: evidence becomes an argument, a person can contest it, repair is scoped to the failing path, and only verified experience enters durable memory.

Problem: A correction that overwrites the whole system destroys provenance and can create unsafe transfer.

Design move: Keep arguments, conflicts, revision scope, and verification status visible.

1 · SEMV makes memory earn its permanence

fresh researchverification-gated memory

SEMV connects multimedia evidence, agent reasoning, human contestation, and long-term memory through provenance-bearing arguments. Its reported system reduces negative transfer from 5.7% to 0.2%; on a contestation-derived benchmark, scoped revision corrects 96.7% of initial errors while saving 52.8% compute.

  • Store evidence with every claim
  • Preserve disagreement instead of flattening it
  • Revise the causal path that failed
  • Admit memory only after verification

Buildn/client use: Make every research artifact carry source, claim, confidence, reviewer challenge, repair status, and memory eligibility.

Action: Add memory_status: candidate | verified | rejected to one artifact schema.

2 · Coaching should not leak the answer

randomized studyprocess quality

A clinical interview training study separates a patient agent, Socratic tutor, and turn-level evaluator. Students trained with scaffolding improved final examination scores, especially communication, empathy, and history-taking, without a significant diagnostic-accuracy advantage.

Why it matters: The system supports the process while preserving an independent patient-only assessment. That is a useful model for agent onboarding, client enablement, and operator training.

Action: Separate “help during work” from “judge final work” in the next Buildn workflow; test transfer without the coach present.

3 · Shared scratchpads are control surfaces

emergent behaviorlocal visibility

The “copying” paper argues that short-lived agents can form stable conventions by imitating what is locally visible and recent. No explicit coordination or persistent memory is required. Early examples can therefore create path dependence.

Buildn/client use: Treat shared notes, recent edits, and default examples as policy-bearing inputs. Seed them deliberately; audit what a new agent sees first.

Action: Run a two-condition test: identical task, different initial scratchpad. Compare downstream conventions and error clusters.

A shared artifact is not passive context when agents copy from it.
