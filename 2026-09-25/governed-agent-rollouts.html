1 · GitHub's 28-day governance window

published 24 Sepenterprise policy
  • Effective: 22 Oct 2026
  • Choices: enabled · disabled · organizations decide
  • Scope: eligible GA features, Code Review, MCP policies

GitHub is adding a global default for unconfigured Copilot capabilities. Explicit choices remain intact; previews stay opt-in. The useful idea is not the product setting—it is the separation between a global default and an exception register.

Buildn/client use: Define capability classes, choose safe defaults, and require an explicit record for every deviation.

Action: Draft a one-page agent capability register with owner, default, exception, review date, and rollback.

Do not wait for rollout day: the policy becomes consequential on 22 October.

2 · ARIA: govern the population, not only the agent

researchregulated finance

The ARIA proposal names “constitutional non-compositionality”: each agent can pass local controls while their shared signals and interactions create collective disparate impact, drift, or accountability gaps.

  • Policy specification before deployment
  • Bounded authority per agent
  • Runtime containment and stop paths
  • Observed-versus-expected population monitoring
  • Human oversight competence

Buildn/client use: Add a portfolio view to agent reviews: shared inputs, aggregate outcomes, interaction effects, and drift—not just prompt-level quality.

Action: Pick one client workflow and define its expected outcome distribution before automating it.

3 · Regulated insurer architecture

reference architectureMCP + A2A

This paper decomposes insurance work into capital, underwriting, claims, compliance, fraud, and client-interaction agents. A supervisory orchestrator coordinates them under Solvency II, the EU AI Act, role-sensitive access, and human-in-the-loop controls.

Why it matters: It is a concrete vocabulary for separating domain authority from orchestration authority. The orchestrator is not “the smart agent”; it is the admissibility and coherence boundary.

Action: For a regulated client, draw three planes: domain agents, supervisory control, and human approval. Label every tool call with its authority source.
