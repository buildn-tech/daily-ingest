Agent Substrate on GKE

selecteddocs
  • updated: 2026-11-05
  • source: docs.cloud.google.com

What it is

The runtime separates stateful actors from warm workers and restores paused sessions in under 500 ms according to Google.

Buildn / client use

Use the actor/worker split as a reference architecture for long-running jobs that wait on human review or external tools.

Follow-up

Map one current Hermes job onto actor, gateway, snapshot, and worker responsibilities.

Caveat: Managed GKE availability may not match a local or multi-cloud deployment model.

gVisor

selectedproject
  • updated: 2026-11-05
  • source: gvisor.dev

What it is

A userspace application kernel offers a stronger boundary for agents that execute generated code or untrusted packages.

Buildn / client use

Offer isolated per-task execution for client analysis and code repair without granting a job a shared host-kernel trust level.

Follow-up

Compare gVisor with the current sandbox boundary using a hostile-package test.

Caveat: Isolation is not permission management; network and secret policy remain separate.
