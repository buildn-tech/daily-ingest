Local sandboxing for GitHub Copilot

selectedrelease
  • source: https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available

What it is. GA sandboxing restricts filesystem, network, credentials, MCP servers, and local services across Copilot CLI, app, and VS Code Agent Host.

Why it matters. Use the model/tool split as a Buildn rule: changing the model must not silently change the tool boundary.

Try next. Run one local agent workflow with read-only project scope and blocked credential access.

Caveat: Policies may differ by OS and supported tool; test the actual boundary.

  • Bounded action over vague autonomy

GitHub package firewall

selectedrelease
  • source: https://github.blog/changelog/2026-10-20-github-package-firewall-in-public-preview

What it is. An install-time npm gate checks metadata and downloads against cooldown, advisory, and supply-chain policies.

Why it matters. Add a package-intake gate before any agent-generated build or report pipeline installs dependencies.

Try next. Prototype a cooldown plus exception workflow for client-facing automation.

Caveat: Public preview; npm only; pricing is expected to become metered.

AI Scan for pull requests

selectedrelease
  • source: https://github.blog/changelog/2026-10-15-ai-scan-for-pull-requests-generally-available

What it is. AI Scan covers languages and frameworks outside CodeQL’s current reach, but findings remain advisory and cannot block merges.

Why it matters. Treat AI security output as a second signal in a review packet, not as an approval substitute.

Try next. Enable it on a low-risk repo and compare findings with CodeQL.

Caveat: Fork and Dependabot PRs are excluded; credits need budgets.

  • Bounded action over vague autonomy

Agentic autofix for code scanning

selectedrelease
  • source: https://github.blog/changelog/2026-10-15-agentic-autofix-for-code-scanning-alerts-general-availability

What it is. Copilot explores the repository, proposes a multi-file fix, reruns CodeQL, and opens a draft PR for review.

Why it matters. This is a reusable governed loop: diagnose → patch → verify → request human review.

Try next. Use a batch of non-critical alerts to measure verification quality and time saved.

Caveat: Default-branch only; consumes AI credits and Actions minutes.
  • Evidence before enthusiasm
  • Bounded action over vague autonomy

Expiring, auto-refreshing GitHub CLI credentials

selectedrelease
  • source: https://github.blog/changelog/2026-10-21-github-cli-opt-in-to-expiring-auto-refreshing-oauth-tokens

What it is. GitHub CLI v2.103.0 can replace long-lived tokens with short-lived access plus rotating refresh tokens.

Why it matters. Prefer fresh credential reads at tool invocation time; never put a cached token in a durable run artifact.

Try next. Audit scripts that call gh auth token and remove token persistence.

Caveat: Opt-in preview; external consumers must retrieve the token each time.
  • Evidence before enthusiasm
  • Bounded action over vague autonomy

GitHub Copilot assisted permissions

selectedrelease
  • source: https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available

What it is. A new permission surface makes agent actions more explicit instead of treating every tool request as equivalent.

Caveat: Verify exact availability and policy behavior in the target organization.
