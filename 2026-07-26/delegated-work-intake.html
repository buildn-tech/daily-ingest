1. Copilot cloud agent for Linear is now generally available

What it is
GitHub Copilot cloud agent can be assigned from Linear to work asynchronously in an ephemeral GitHub Actions environment, update the issue timeline, and open a draft pull request.
Buildn / client use
Pilot a low-risk maintenance issue where the acceptance criteria and repository are unambiguous.

Why useful now: This fills a coverage gap between agent capability and portfolio coordination: the fresh signal is not another coding model, but a clearer handoff from a work item to a supervised draft PR.

Caveat: Setup requires both organization-owner and Linear-workspace-admin permissions; a draft PR is still not an accepted change.

Follow-up action: Create a Linear label for agent-eligible work and require a testable definition of done before delegation.

2. AI Agents — Linear Docs

What it is
Linear keeps the human as primary assignee when work is delegated, supports team-scoped agent access, and records guidance with full history.
Buildn / client use
Use workspace guidance for universal delivery rules and team guidance for repository, review, and client conventions.

Why useful now: This fills a coverage gap between agent capability and portfolio coordination: the fresh signal is not another coding model, but a clearer handoff from a work item to a supervised draft PR.

Caveat: Each third-party agent has its own data handling and interpretation of guidance.

Follow-up action: Write a short guidance baseline: allowed repos, required checks, PR naming, and escalation triggers.

3. Multi-select fields for Projects and Issues in public preview

What it is
GitHub Projects and Issue fields can now hold multiple values, enabling one item to be tagged by several teams, modules, or work categories.
Buildn / client use
Model client impact, workstream, risk, and agent eligibility without forcing a single category.

Why useful now: This fills a coverage gap between agent capability and portfolio coordination: the fresh signal is not another coding model, but a clearer handoff from a work item to a supervised draft PR.
