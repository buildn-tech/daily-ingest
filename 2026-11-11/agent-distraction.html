Thesis: knowledge maintenance is an agent-performance intervention.

Agent Distraction

fresh research · primary

Google Developers Blog · 6 Nov 2026 · thousands of engineers, millions of sessions

What: Google studied how stale inline bug references redirect coding agents. 13% of sessions encountered a bug reference; 6% triggered a related action; 83% of those actions were unprompted.

Measured cost: unprompted detours produced 70% more steps, 77% more tokens, and 105% more wait time in the analysis.

Use: add a context-hygiene pass to repositories and agent prompts. Remove only references proven obsolete through issue history, file history, related changes, and original intent.

Caveat: automated deletion can erase load-bearing intent. Cleanup needs evidence and review, not regex alone.

Next: scan one active repo for stale TODO/FIXME references and classify them before changing anything.

Context hygiene as a delivery control

Buildn opportunity

Most agent systems measure requests and outputs, but not the quality of the context they traverse. A lightweight hygiene score can expose avoidable cost before model tuning.

  • Reference age and issue status
  • Prompt-scope alignment
  • Detour count and recovery
  • Human correction after detour
The cheapest token is the one a clean repository never asks the agent to spend.
