Security Verification as an Agent Capability

Security automation is becoming a capability layer with proof obligations. Anthropic’s verification program reports thousands of verified vulnerabilities, while CodeQL 2.27.2 expands analysis across C++, Go, Rust, and JavaScript. The practical move is to make agent output carry findings, scope, and validation—not just a confident summary.

Selection rationale: Security earns a second look because Oct 9 updates materially deepen prior trust coverage: Anthropic reports 5,500 verified vulnerabilities and GitHub shipped a meaningful CodeQL release.
