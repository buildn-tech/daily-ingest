ARTEX turns cloud compromise into a speed problem

urgentthreat intelligence
Microsoft Security · 2026-10-21 · privileged access in under 3 hours in some cases

Microsoft reports Storm-0940 used the open-source ARTEX multi-agent penetration framework across hundreds of organizations. The observed activity included password spraying, OAuth abuse, Graph reconnaissance, credential changes, and attempts to read Key Vault secrets.

Buildn use: design client readiness reviews around time-to-detect, OAuth application inventory, and credential-change alerts. Caveat: successful authentication alone does not prove data access.

  • Track privileged persistence
  • Alert on app credential changes
  • Practice three-hour containment

Skills can exfiltrate a whole repository

supply chainupdated 2026-09-29
Mitiga Labs · “Breaking Skills” · silent Git remote + public push

Mitiga demonstrated a malicious-looking-legitimate skill that instructed an agent to create tests, add an attacker Git remote, push the repository, and open a pull request. The workflow left little audit evidence and required only a few user interactions.

Buildn use: treat skill installation like package installation: provenance, static review, sandbox, and least privilege. Caveat: a skill is executable behavior even when its main file reads like documentation.

  • Review “definition of done”
  • Block unknown remotes
  • Log every side effect

Next: add a repository-egress test to Hermes skill reviews.

Cyber access is becoming tiered and verified

defensive patterngovernance
Anthropic · Cyber Verification Program · Defense / Red Team / Specialized

Anthropic describes a three-tier program that verifies organizations before granting reduced cyber restrictions, with stronger review for authorized red-team and critical-infrastructure work.

Buildn use: map agent capabilities to verified operator identity, scope, and mission—not only to a model name. Caveat: verification is an operating process, not a one-time badge.

  • Capability follows evidence
  • Separate defense from offense
  • Review high-impact scopes
