Agents API: runtime primitives become a product surface

high leverageAPI / infrastructure
  • Source: OpenAI
  • Public beta announced: 2026-09-10
  • Key primitives: sessions, compaction, tool search, subagents, sandboxes

What it is: A managed harness for long-running cloud agents, with automatic context compaction, tool discovery, programmatic tool calling, MCP, subagents, and selectable execution environments.

Why it matters: These primitives define the difference between a chat wrapper and an operable agent system.

Buildn/client use: Model recurring research, QA, and delivery jobs as sessions that emit evidence and artifacts—not just final text.

  • Design for recovery from day one
  • Keep tool catalogs lazy
  • Make artifacts the contract
Caveat: the source is a product announcement; benchmark reliability, isolation, cost, and portability in a representative workload.

Follow-up: Take one scheduled Buildn job and specify its session state, recovery point, tools, and artifact outputs.

Gemini 4 Carbon: deep reasoning as a routed tier

trial candidatemodel economics
  • Available: 2026-11-10
  • Intro price: $2 input / $10 output per 1M tokens
  • Post-intro price: $4 input / $20 output

What it is: Google’s deepest-reasoning Gemini tier for long-horizon agentic workflows, difficult software engineering, science, multimodal documents, and cybersecurity.

Why it matters: The useful question is not “which model wins?” but “which task deserves the expensive loop?”

Buildn/client use: Route architecture, adversarial review, and high-ambiguity synthesis to Carbon; keep routine extraction and formatting on a faster tier.

  • Route by task difficulty
  • Measure cost per completed artifact
  • Reserve depth for verification
Caveat: vendor benchmarks and introductory pricing can move; reproduce on your own task mix before changing defaults.

Follow-up: Run a 20-task bakeoff with three buckets: routine, ambiguous, and verification-heavy.
