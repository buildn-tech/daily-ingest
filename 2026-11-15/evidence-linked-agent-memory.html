Evidence-Linked Agent Memory

The strongest memory pattern is not “store more context.” It is selective consolidation with a trail back to evidence, plus benchmarks that test whether memory improves later work without regressions. That maps directly to Buildn’s durable project context and dossier continuity.

Solid boxes = practical stages · green = action or evidence · amber = review point

Signal map

Memory has been under-covered relative to infrastructure and security, and two current research signals make the practical design rule sharper: memory must learn from experience and remain auditable.

  • Choose a bounded workflow
  • Keep evidence attached
  • Pause before irreversible action

01 · The Sleep Framework: Continual Learning for LLMs

selectedresearch2026-10-27
  • source: https://research.google/blog/the-sleep-framework-a-new-way-for-llms-to-retain-knowledge-in-continual-learning/

What it is

Google Research separates active interaction from offline consolidation, using a periodic sleep phase to stabilize new knowledge.

Buildn / client use

Borrow the wake/sleep split for ingest: collect during the day, consolidate only after review.

Why useful now

It supplies a concrete design or evaluation primitive instead of another generic capability claim.

Caveat: Parametric consolidation is costly and experimental; do not equate it with ordinary retrieval.

Follow-up

Add a nightly “candidate memory” pass with approval.
