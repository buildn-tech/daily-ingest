Dossier cards

Creative AI is moving into the canvas

strong signaldesign systems
  • source: www.figma.com

What: Figma frames AI as part of the creative process while keeping human taste and decision-making central.

Why it matters: The opportunity is not “generate a screen”; it is compressing iteration while retaining intent.

  • Keep rationale and rejected directions as first-class artifacts.
  • Try next: Run a client concept sprint with explicit human review checkpoints.
Caveat: Editorial framing is not evidence of production quality.

Local code closes the design-to-delivery seam

strong signallocal-first
  • source: www.figma.com

What: Figma Make is presented as working with local code, reducing the distance between generated prototypes and the developer’s environment.

Why it matters: Local ownership makes generated work easier to inspect, test, and continue after the tool session.

  • Prefer exports that compile, diff, and run outside the editor.
  • Try next: Test one exported prototype through a normal git branch and CI check.
Caveat: Tool support and fidelity can vary by project and framework.

Design agents need domain fluency, not generic generation

strong signalmodel specialization
  • source: www.figma.com

What: Figma’s design agent and fluent editing model work toward understanding design structure, systems, and intent.

Why it matters: Domain-specific models can make agent output more useful than general-purpose image or code generation.

  • Encode tokens, components, constraints, and rationale as machine-readable context.
  • Try next: Export a small design system schema and use it as agent context.
Caveat: Specialization can increase lock-in to one design tool’s representation.

MCP can connect the canvas to the workflow

strong signaltool interoperability
  • source: www.figma.com

What: Figma’s MCP workflow material shows design context and actions crossing into agent tooling.

Why it matters: The highest-leverage loop connects design decisions to implementation and back to visual verification.

  • Treat MCP tools as typed, scoped interfaces—not a magic context dump.
  • Try next: Build one design-review tool that returns source links and diffs.
Caveat: MCP connections can leak sensitive project context without policy controls.
