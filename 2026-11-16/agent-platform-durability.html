Dossier cards

Agent platforms now need an exit path

watchplatform lifecycle
  • source: openai.com

What: OpenAI says Agent Builder and Evals will be wound down after Nov 30, 2026, pointing users toward code-first Agents SDK or Workspace Agents.

Why it matters: A visual builder can accelerate discovery while still creating migration debt. Treat hosted orchestration as a disposable surface, not the system of record.

  • Keep prompts, eval fixtures, traces, and tool contracts in versioned files.
  • Try next: Inventory any no-code workflow and export its contract before the cutoff.
Caveat: The notice is provider-specific; it does not imply every managed agent product is short-lived.

Durable workflows are becoming encrypted event logs

strong signalworkflow runtime
  • source: vercel.com

What: Workflow SDK 5 adds encrypted event-log persistence, steps, and agent-ready performance primitives.

Why it matters: Long-running agents need resumability and privacy as defaults, not bespoke infrastructure.

  • Model runs as replayable state transitions, not chat sessions.
  • Try next: Prototype one Buildn job with explicit step boundaries and a replay test.
Caveat: Encryption and durability do not solve incorrect side effects; idempotency still matters.

Tool approval is an interface primitive

strong signalagent UX
  • source: vercel.com

What: AI SDK 6 exposes per-tool approval, input examples, and devtools for inspecting agent behavior.

Why it matters: Human checkpoints become composable UX rather than a gateway-specific hack.

  • Use risk-tiered approval: read-only, reversible write, irreversible write.
  • Try next: Add a tool policy field to one Hermes tool and measure approval friction.
Caveat: Approval prompts can become click-through noise if every tool is gated equally.

Agent SDKs are shifting from chat to research primitives

strong signalagent runtime
  • source: blog.cloudflare.com

What: Cloudflare Project Think describes new Agents SDK primitives for building agent systems on its edge platform.

Why it matters: The competitive boundary is durable coordination and state, not another chat wrapper.

  • Compare state, scheduling, and handoff primitives across providers.
  • Try next: Map Buildn’s session, cron, and artifact concepts to a provider-neutral interface.
Caveat: Vendor-native primitives may deepen coupling to one deployment model.
