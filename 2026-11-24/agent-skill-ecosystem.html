CLI-Anything: making all software agent-native

Goodrepo+paper
  • github.com/HKUDS/CLI-Anything · ~64k stars, 790/day
  • CLI-Hub registry: clianything.cc
  • companion paper arXiv 2606.03854

what: A HKUDS project that generates agent-native CLIs for existing GUI software, with a hub registry so agents can discover, install and drive ordinary desktop apps.

why: Generalizes "agent experience" from dev tools to all software; the registry pattern is exactly the discoverability layer Buildn hosted-MCP plans need.

caveat: Generated CLIs inherit the app's quirks; trust boundary is whatever the underlying app allows.

Agent-Reach v1.6: internet access for agents

Goodrelease
  • github.com/Panniantong/Agent-Reach · ~114k stars

  • Twitter, Reddit, YouTube, GitHub, Bilibili

what: A CLI that gives agents structured read/search access to major social and code platforms with zero API fees, now hardened in a 1.6 refactor.

claude-mem: persistent context across sessions

Specmemory
  • github.com/thedotmack/claude-mem · ~119k stars
  • works with Claude Code, Codex, Gemini, Hermes
  • compresses sessions, reinjects context

what: Agent-agnostic persistent memory: captures session activity, compresses it with AI, and reinjects relevant context in future sessions.

why: Session-to-session continuity is the gap between demos and assistants; its model-agnostic claim is worth benchmarking against Hermes' built-in memory.

caveat: Compression loses detail; watch for confident-but-wrong recall.

action: Run one week of parallel notes: claude-mem vs your current memory, diff recall quality.

Specproduct
