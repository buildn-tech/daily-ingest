Memory Echo + MEchoBench

paperfresh signal
  • source: https://arxiv.org/html/2610.17763v1
  • follow-up: Instrument one memory store for parent IDs, derivative counts, and supersession.

What it is

Repeated retrieval and write-back can make one historical claim look like independent evidence; MEchoBench measures echo density, persistence, and contamination.

Why it matters

A memory can remain stored without deserving equal retrieval exposure after correction.

Buildn / client use

Add source-family IDs, correction status, and authority to any durable agent memory.

MemComposer

paperfresh signal
  • source: https://arxiv.org/html/2610.21091v1
  • follow-up: Compare top-k retrieval with variable-length selection on ten real tasks.

What it is

A learned composer chooses which memories to include, how many, and in what order, optimizing complete task outcomes rather than similarity alone.

Why it matters

The result challenges fixed top-k retrieval: more context can reduce performance and raise cost.

Buildn / client use

Use a bounded memory-selection stage before the main agent, with token and success budgets.

Next move: Compare top-k retrieval with variable-length selection on ten real tasks.
