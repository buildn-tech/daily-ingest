Signal map

Cloudflare shipped first-party AI Search guides for three agent ecosystems today. This is a practical coverage gap: retrieval can now sit behind the same framework interfaces used for Buildn and client agents, with sources returned to the calling workflow.

Framework-native AI Search

What: AI Search now has integration guides for Cloudflare Agents SDK, Vercel AI SDK, and LangChain.

Why now: It lowers the integration cost of a grounded assistant; the retrieval layer can follow the agent framework rather than forcing a new orchestration stack.

Use: Buildn OS: source-backed workspace answers. Client: scoped project knowledge assistant. Agents: a named retrieval tool. Personal: research with traceable links.

Caveat: Confirm index tenancy, document permissions, retention, and citation behavior before production use.

Next: Create one 20-document pilot; log answer, source set, and missed retrievals.

AI SDK: chat plus tool

What: The AI SDK guide supports an AI Search chat interface and explicit instance.search() tool exposure.

Why now: This creates two controllable patterns: retrieval-led conversations or model-led tool invocation.

Use: Buildn OS: answer a help query. Client: allow a project agent to fetch approved facts. Agents: require source capture per tool call. Personal: use one curated namespace.

Caveat: Tool descriptions and result limits shape behavior; do not treat retrieved text as authority without evaluation.

Next: Implement both patterns against the same questions; compare citation completeness.

docsdirect source

LangChain retriever path

What: The LangChain integration adds CloudflareAISearchRetriever for standalone retrieval, retriever tools, and RAG chains.

Why now: It offers a direct bridge when a client already has LangChain rather than a reason to rebuild their chain.

Use: Buildn OS: reuse a retrieval contract. Client: add hybrid search to a service agent. Agents: expose a retriever tool. Personal: test cross-source queries.

Caveat: Framework adapters do not solve content quality or access control; assess both separately.

Next: Run a fixed 15-question set with hybrid retrieval and inspect the returned documents.
