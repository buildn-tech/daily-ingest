Workers, now in your Notion credits dashboard

WhatNotion now exposes Workers usage in its credits dashboard; Workers run custom code for syncs, Custom Agent tools, and webhook automation.
Why it mattersIt makes consumption visible while Workers are free to try in beta, giving teams a chance to establish a baseline before paid usage.
Use nowInstrument one low-risk knowledge sync or webhook tool, then record executions, user value, and projected credits per outcome.

Caveat: Dashboard visibility is not a spend limit; beta terms and future pricing can change.

Follow-up: Define a per-workflow budget and owner before enabling a persistent automation.

Cloudflare budget alerts default on

WhatEligible pay-as-you-go accounts without an alert receive a $10 account-level budget alert at their next billing cycle.
Why it mattersThis is a useful safety net for experimental Workers, but the alert is informational and usage is processed daily.
Use nowSet tighter, workflow-specific thresholds for client prototypes and pair alerts with application-level rate limits.

Caveat: It neither caps spend nor includes recurring plan fees; it can arrive a day after the threshold is reached.

Follow-up: Audit current alerts, add a named operator, and document the shutdown path for costly automations.

fresh signalprimary source

Cloudflare Durable Objects storage monitoring

WhatThe current platform changelog adds a Total storage chart for SQLite-backed Durable Object namespaces.
Why it mattersStateful agent workflows need storage growth to be observable, especially when transcripts, artifacts, and job state accumulate.
Use nowUse namespace storage trend as a release gate for persistent workflow pilots.

Caveat: The chart is namespace-level; it does not identify a single object by ID or name.

Follow-up: Set a weekly storage review and retention policy before storing agent artifacts.
